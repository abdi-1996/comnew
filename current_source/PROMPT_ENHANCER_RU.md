# Comfy Remote 1.1.0 — локальный Prompt Enhancer

## Что это

Prompt Enhancer работает **только на iPhone**. На Windows не устанавливается отдельная LLM и видеокарта ПК не используется для улучшения текста.

В первой версии используется лёгкая локальная модель **Qwen3 0.6B Q8_0 (около 639 МБ)** через iOS XCFramework `llama.cpp`. GGUF не входит в IPA: он скачивается по кнопке внутри приложения, проверяется по размеру и заголовку GGUF и хранится в Application Support на iPhone.

## Первый запуск

1. Откройте Positive Prompt.
2. Нажмите **Enhance**.
3. Нажмите **Скачать Prompt Enhancer**.
4. После загрузки выберите Light, Detailed или Creative.
5. Нажмите **✨ Enhance**.
6. Проверьте результат и нажмите **Применить**.

Модель можно удалить из того же окна. После завершения одного Enhance runtime освобождается — приложение не держит LLM постоянно загруженной в памяти.

## Профили знаний

Приложение автоматически подбирает локальные инструкции по активному workflow/checkpoint:

- WAN 2.2 — действие, план, ракурс, одно основное движение камеры, движение объекта, свет, настроение, стиль.
- Z-Image — связный natural-language image prompt.
- Z-Image Turbo — более короткий natural-language prompt без лишних повторов.
- SDXL — компактная структура subject / pose / composition / environment / light / camera / style / detail.

Если сервер старой версии не распознал checkpoint, iPhone дополнительно пытается определить профиль по имени checkpoint.

## Template Builder

Templates теперь идут по структуре выбранной модели. В одиночных категориях новый вариант заменяет старый и автоматически открывается следующий шаг. В категории «Детали» разрешён множественный выбор. Выбранные слоты сохраняются локально: если снова открыть Builder и заменить только освещение/камеру/объектив, предыдущий слот заменится, а не продублируется.

Добавлены ракурсы, свет, реальные камеры, объективы, эмоции, взгляд, позы, Instagram lifestyle-сцены, стили, детали и отдельные video-шаблоны WAN 2.2.

## Advanced

Числовые параметры получают кнопки `−` и `+` рядом со значением. Шаг подбирается по типу параметра:

- Seed: 1
- Steps / Batch: 1
- CFG: 0.1
- LoRA strength / strength / denoise: 0.05
- Width / Height: 64

Ручной ввод значения сохранён.

## Generate с новым seed

Return/Go в Positive Prompt теперь закрывает клавиатуру, создаёт новый случайный seed и запускает генерацию. На панели клавиатуры также есть **🎲 Generate** с тем же поведением.

## Сборка

GitHub Actions перед Xcode build скачивает официальный `llama.cpp` iOS XCFramework закреплённой версии `b10453`. Сам GGUF в IPA не добавляется: workflow отдельно проверяет отсутствие `.gguf` внутри собранного приложения.
