# Tailscale на экране входа — 1.1.4

1. Запустите PCRemoteServer 5.2.4 на Windows.
2. iPhone должен видеть ПК хотя бы по LAN/ZeroTier, чтобы удалённо включить Tailscale, если он сейчас выключен.
3. Введите пароль подключения.
4. Нажмите **Tailscale на ПК**.

Если ПК вообще недоступен по сети и Tailscale уже выключен, iPhone физически не может включить его без другого доступного канала к Windows.
