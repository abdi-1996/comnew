# Comfy Remote 1.1.3 — Tailscale + Load LoRA

## Tailscale

На главном экране Comfy Remote появилась карточка `Tailscale ON/OFF`.

- `ON` — Tailscale включён на Windows-ПК.
- `OFF` — Tailscale выключен.
- Долгое нажатие по карточке → `Обновить статус`.
- Если телефон сейчас подключён к серверу именно через Tailscale, перед выключением появляется предупреждение. После выключения удалённое соединение пропадёт, если нет LAN/другого маршрута.

Windows-агент использует установленный `tailscale.exe` и команды `tailscale up` / `tailscale down`.

## Load LoRA в редакторе нод

Каталог нод берётся непосредственно из `/object_info` текущего ComfyUI.

- LoRA-ноды находятся в отдельном верхнем разделе `LoRA`.
- Стандартный класс `LoraLoader` показывается как `Load LoRA`.
- Кнопка обновления справа сверху заново получает `/object_info`.
- Если `LoraLoader` отсутствует при первом открытии, приложение автоматически выполняет принудительное обновление.
- Каталог больше не обрезается до первых 160 нод, поэтому custom nodes не должны вытеснять стандартные ноды из списка.

## Что обновить

Для этих функций нужно обновить и IPA, и Windows PC Remote Server из одной версии проекта.
